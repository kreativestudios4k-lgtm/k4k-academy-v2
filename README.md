# K4K Academy V2

Premium Next.js landing page for the £7.99/month K4K Academy membership.

## Run locally
npm install
npm run dev

## Deploy to Vercel
Import this repository into Vercel. Framework: Next.js. No special build settings required.

## Before launch
1. Replace the email CTA in app/page.js with your real Stripe £7.99/month Checkout/Payment Link.
2. Replace the showreel placeholder with your own optimized MP4/WebM or hosted video player.
3. Confirm the displayed social proof metrics are still current.
4. Replace hello@kreativestudios4k.com if you use another support address.
5. Add Privacy, Terms, Refund/Cancellation and Cookie pages before accepting subscriptions.

## Design
Dark cinematic K4K identity, lime accent, responsive mobile layout, curriculum, prompt drops, social proof, 1:1 upsell, FAQ and membership CTA.
